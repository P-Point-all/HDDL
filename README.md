Concernant les poids des modèles utilisés:

Les poids sont sur le répertoire Drive suivant: https://drive.google.com/drive/folders/1w1IPk9uMVMp-zlazLFzwf4b41nKBjdE4?usp=drive_link.

Pour les utiliser, il faut simplement suivre l'arborescence du répertoire:

* Dans le dossier weights, les poids des modèles qui sont déjà dedans.
* Dans le dossier infos_entrainement, les .pth qui sont dedans également.

* Enfin, pour les datasets, il faut télécharger le zip dans le répertoire principal et l'extraire sur place.
On aura donc pour un dataset donné une arborescence de la forme:
main/dataset/dataset/<contenu>
